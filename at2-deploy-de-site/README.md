# 🎬 Linkando páginas em HTML
## 📝 Descrição do Projeto
Este projeto consiste em um sistema inteligente de gestão financeira e controle de orçamento, projetado para auxiliar os usuários na organização de despesas, receitas, metas e relatórios financeiros. O objetivo principal é mitigar a complexidade na tomada de decisões financeiras, oferecendo uma interface intuitiva e funcionalidades de acompanhamento de fluxo de caixa baseadas nas preferências e registros do usuário.Desenvolvido como parte das disciplinas de Desenvolvimento Front-End Para Web (2026.2), o sistema processa dados de transações e relatórios para identificar padrões de gastos e fornecer uma visão clara da saúde financeira, utilizando ferramentas web modernas para uma experiência de usuário eficiente.
## 🚀 Tecnologias Utilizadas
* **Linguagem:** HTML5, CSS 
* **Bibliotecas:** Bootstrap
* **Ferramentas:** VSCode
* **Modelo de IA:** Claude
## 📊 Resultados e Aprendizados
O projeto alcançou resultados sólidos em ambiente de teste, demonstrando
a eficácia do modelo híbrido.
* **O modelo atingiu 92% de acurácia** nos testes de validação.
* **Redução de Ruído:** Aprendi a aplicar técnicas de limpeza e
normalização de dados para melhorar a performance dos algoritmos.
* **Visualização de Clusters:** Implementei gráficos que mostram como o
sistema agrupa filmes por afinidade.
## 🧠 Declaração de Uso Ético da IA
Este projeto utilizou inteligência artificial (Claude) estritamente como ferramenta de suporte
tecnológico para finalidade de estruturação inicial do HTML e CSS e criação de imagens. Todo o código gerado foi revisado,
testado e compreendido por mim, garantindo a minha responsabilidade
integral sobre a autoria final, integridade e funcionamento da
aplicação.
